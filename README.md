## Завдання. 

**Завдання:** 

Розробити консольну програму __«Система обліку замовлень»__ для служби доставки або інтернет-магазину.

Програма повинна зберігати інформацію про одне замовлення:

• номер замовлення;

• основний параметр замовлення (вага, кількість товарів тощо);

• вартість замовлення.

Для кожної величини необхідно:
1. створити звичайну змінну;
2. створити вказівник на змінну;
3. вивести значення змінної;
4. вивести її адресу;
5. вивести адресу через вказівник;
6. вивести значення через вказівник;
7. змінити значення змінної через вказівник;
8. повторно вивести змінене значення.

Окремо створити функцію, яка отримує вказівник на вартість замовлення та змінює її відповідно до умови свого варіанта.

**Важливо**

У роботі **не використовувати struct, класи, масиви та інші складні конструкції**.

№  | Система | Номер замовлення | Параметр | Початкове значення | Зміна вартості | Початкова вартість 
-- | ------- | ---------------- | -------- | ------------------ | -------------- | ------------------
3  | Rozetka | 317              | вага     | 1.7 кг             | +200 грн       | 1800 грн

### 💻 Код програми:

```
#include <iostream>
using namespace std;

void changePrice(double* price) {
    *price = *price + 200.0;
}

int main() {
    int orderNumber = 317;
    int* orderNumberPtr = &orderNumber;

    cout << "=== Номер замовлення ===" << endl;
    cout << "Значення змінної: " << orderNumber << endl;
    cout << "Адреса змінної: " << &orderNumber << endl;
    cout << "Адреса через вказівник: " << orderNumberPtr << endl;
    cout << "Значення через вказівник: " << *orderNumberPtr << endl;

    *orderNumberPtr = 350;
    cout << "Новий номер замовлення: " << orderNumber << endl << endl;

    double weight = 1.7;
    double* weightPtr = &weight;

    cout << "=== Вага замовлення ===" << endl;
    cout << "Значення змінної: " << weight << " кг" << endl;
    cout << "Адреса змінної: " << &weight << endl;
    cout << "Адреса через weightPtr: " << weightPtr << endl;
    cout << "Значення через weightPtr: " << *weightPtr << " кг" << endl; 
    
    *weightPtr = 2.2;
    cout << "Нова вага: " << weight << " кг" << endl << endl;

    double price = 1800.0;
    double* pricePtr = &price;

    cout << "=== Вартість замовлення ===" << endl;
    cout << "Початкова вартість: " << price << " грн" << endl;
    cout << "Адреса змінної: " << &price << endl;
    cout << "Адреса через pricePtr: " << pricePtr << endl;
    cout << "Значення через pricePtr: " << *pricePtr << " грн" << endl;

    changePrice(&price);
    cout << "Нова вартість: " << price << " грн" << endl;

    return 0;
}
```
